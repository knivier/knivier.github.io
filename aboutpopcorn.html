About Popcorn

UEFI first. Native BOOTX64.EFI, modern display modes, CI on the UEFI image.

Operation map Repository Roadmap

What it is

Popcorn is an exo/mono hybrid kernel for x86-64. A layered core owns interrupts, memory, scheduling, and syscalls. New devices land in Rust. The longer goal is a real kernel on modern firmware, not a demo that only boots under old BIOS tricks.

How it is built

UEFI + GRUB

Primary path is UEFI. GRUB Multiboot2 ISO stays for a second boot check.

C + Rust

Asm/C keep entry, IDT, PMM, and early bring-up. Rust owns drivers, screen backends, pops, and the catalog.

Driver network

Devices register once and show up to the shell. Screen, serial, keyboard, clock, block, and more.

Pop modules

Small add-ons (sysinfo, cpu, memory, uptime, …). Dolphin is the in-kernel editor.
