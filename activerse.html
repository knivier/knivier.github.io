What is Activerse?

Activerse Frameworks are a collection of 2D and 3D game frameworks by Knivier. They are designed to be flexible and easy to use, with a focus on performance and ease of development.

Activerse Origin

The 2D Java game framework. Physics, graphics, sound, and a customizable actor/world API.

Activerse Frontier v1.0

Day 1 in development

A 3D game framework is on the way, with a familiar codebase derived from Activerse Origin.

3 Dimensionality Rust core for performance and safety Keeps old architecture & language Java-only scripting

What is it?

It's Activerse origin but with another dimension; a 3D game framework that uses familar codebase and development practices to origin.

Language Hierarchy

Java is the primary scripting and engine language, with core components being rewritten in Rust for performance and safety.

What to expect

A much faster and safer engine, with a more powerful and flexible API for developers, while keeping Java-only scripting.

Release Date

Activerse Frontier will be released on November 1st, 2026. The code will be open source and public on the same day.

What's being retained?

Your detailed debugging setup, advanced logging capabilities, clear and UTD documentation, and stability; all on day 1 of launch.
