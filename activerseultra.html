Activerse Ultra v1.0.0

Minimal custom 3D Java game engine with an Actor based workflow. Subclass Actor, override act(), call Activerse.start(world).

External dependency

LWJGL only, using GLFW and OpenGL.

Run snapshot

./run.sh mvn -q compile exec:exec

Core launch flow

class MyActor extends Actor { @Override public void act() { // behavior loop } } Activerse.start(world);

Requirements

  • JDK 17+
  • Maven 3.9+
  • macOS: -XstartOnFirstThread required

Packages

Package Role
ActiverseEngine Activerse, World, Actor, Camera, Input, GameLoop, FirstPersonController, Collision, MemoryTracker, LogViewer
ActiverseRender Window, Renderer, Shader, Mesh, Texture, ChunkMesher, Hud
ActiverseUtils Math (Vec3, Mat4), EngineLog, helpers
Demo SandboxWorld, Block, BlockGrid

Feature pulse

  • Procedural block texture atlas
  • Chunk mesh with face culling
  • HUD with crosshair, FPS, memory, GC, and logs
  • EngineLog files driven by Activerse.properties

Control hints

  • Mouse look
  • Shift sprint, Space jump
  • LMB or Q break, RMB or E place
